›/paper read arxiv:1706.03762
📄 Attention Is All You Need — Summary
Background RNN/LSTM dominated seq-to-seq tasks but were inherently sequential,
blocking parallelization and struggling with long-range dependencies.
Method The Transformer — encoder-decoder built entirely on multi-head self-attention
and position-wise FFNs. No recurrence, no convolutions.
Results 28.4 BLEU (EN-DE), 41.8 BLEU (EN-FR) — new SOTA at the time,
trained in 3.5 days on 8 GPUs vs. weeks for prior SOTA.
Limitations O(n²) attention complexity; positional encoding is fixed sinusoidal.
Prior Work Extends Bahdanau et al. attention; replaces ByteNet / ConvS2S.

Full Command Reference

Every command at a glance.

/paper add <id|url|path>Import a paper from arXiv, URL, or local PDF
/paper list [--status]List all papers, optionally filtered by read status
/paper search <keywords>Full-text search across titles, abstracts, keywords, notes
/paper web-search <keywords>Search arXiv and import results
/paper show <id>Show full paper details and metadata
/paper tag <id> <tags>Add comma-separated tags to a paper
/paper status <id> <status>Update read status: unread / reading / read
/paper delete <id>Remove from library (PDF file is kept)
/paper read <id>Generate structured 5-section summary
/paper read <id> --mode deepSection-by-section deep read with comprehension checks
/paper read <id> --mode deep --section NJump to a specific detected section
/paper sections <id>List all detected sections in a PDF
/paper explain <id> <phrase>Find and explain a term or passage in context
/paper note <id> <text>Add a freeform note to a paper
/paper notes <id>List all notes for a paper
/paper notes --search <keywords>Search notes across the entire library
/paper export <id> [-o file.md]Export notes to stdout or a Markdown file
/paper related <id>Find related papers with similarity reasons
/paper graph [topic]Visualize library network; optionally filter by topic
/paper survey [topic]Generate a cited survey draft from library + notes
/paper config [--set-lib-dir]Show or change library storage location
